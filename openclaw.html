What is Tailscale?
Tailscale creates a private network between your devices using WireGuard encryption. Each device gets a stable 100.x.x.x IP. Your Mac, VPS, and iPhone are all on this network. It's like having all your devices on the same WiFi, even when they're on different continents. Traffic goes directly between devices (peer-to-peer), not through Tailscale's servers.

Startup Sequence (what happens on boot)
  1. systemd starts openclaw-gateway.service
  2. ExecStart runs openclaw-env-loader.sh
  3. Env-loader reads SA token from /etc/op/token.env
  4. Fetches 7 secrets from 1Password via op read
  5. Exports as env vars (GEMINI_API_KEY, TELEGRAM_BOT_TOKEN, etc.)
  6. Execs the gateway process with all secrets in environment
  7. Gateway loads config from ~/.openclaw/openclaw.json
  8. Boots agent "main" with SOUL.md + USER.md + TOOLS.md
  9. Connects to Telegram bot API, starts listening
