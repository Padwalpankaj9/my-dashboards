What is Tailscale?

Tailscale creates a private network between your devices using WireGuard encryption. Each device gets a stable 100.x.x.x IP. It's like all your devices on the same WiFi, even across continents. Traffic is peer-to-peer, not routed through Tailscale.

How Secrets Flow

No secrets stored in plain text. All credentials live in 1Password (Agent-Secrets vault). At startup, env-loader fetches each and injects into the gateway process.

  • 1Password (Agent-Secrets, 11 items)
  • SA token at /etc/op/token.env
  • env-loader.sh runs op read
  • Exports as env vars
  • Gateway process (secrets in memory only)
