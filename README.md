# My Dashboards

Bespoke personal dashboards, powered by Streamlit.

## Live Apps

| App | Description | Link |
|-----|-------------|------|
| Subscription Tracker | Track all subscriptions, spending trends, student plan alerts | [Open App](https://my-dashboards-pankaj.streamlit.app/) |

## Adding a New App

1. Create a new `.py` file in this repo
2. Push to GitHub
3. Deploy via [share.streamlit.io](https://share.streamlit.io)
4. Add the link to the table above
